Customer Sales Analysis
1. Project Overview
   
This project analyzes Superstore sales data to understand sales performance, profitability, customer purchasing behavior, and regional trends.
The goal is to identify business opportunities, improve profitability, and support data-driven decision-making.
3. Dataset
The dataset is the Sample - Superstore dataset. It contains order details, customers, products, sales, quantity, discount, profit, shipping information, and geographical details.

7. Key Insights
The West region generated the highest sales and profit.
The South region had the lowest total sales among the four regions.
California recorded the highest state-level sales.
November 2017 had the highest monthly sales.
Some months recorded negative profit, highlighting the need to investigate discounts, costs, and product performance.
8. How to Run
Clone or download this repository.
Install dependencies using: pip install -r requirements.txt
Open the notebook in Google Colab or Jupyter Notebook.
Update dataset paths if necessary.
Run the notebook cells in order.
Execute SQL queries from the sql folder using SQLite.
